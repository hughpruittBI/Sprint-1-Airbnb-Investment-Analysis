# Sprint-1-Airbnb-Investment-Analysis

This project analyzes NYC Airbnb data to identify the most attractive neighborhoods and property sizes for short-term rental investment.

### 🔍 Key Insights:
- **Top Neighborhoods:** Battery Park City, Financial District, and Lower East Side had the highest average review activity.
- **Best Property Size:** One-bedroom units were the most frequently reviewed in Harlem.
- **High-Revenue Listing:** ID# 49946551 generated the highest revenue across both monthly and yearly periods.

### 🛠 Tools Used:
- Google Sheets (data cleaning, pivot tables, filtering)
- Excel formulas (TRIM, PROPER)
- Manual data labeling and column standardization

### 📊 Process:
- Cleaned and standardized neighborhood names.
- Created new pivot tables to evaluate reviews and property sizes.
- Documented assumptions, summaries, and changes.
